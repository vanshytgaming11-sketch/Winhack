Module 4.2 — Utility: pair

std::pair (from <utility>, though commonly available via other headers too) bundles two values of potentially different types into a single object. It's used constantly throughout the STL — most notably, every element of a std::map is a pair<const Key, Value>.

1. Declaration & Initialization

#include <utility>
using namespace std;

pair<int, string> p1;                        // default — {0, ""}
pair<int, string> p2(1, "Vinit");               // direct initialization
pair<int, string> p3 = make_pair(2, "Aman");      // make_pair — deduces types automatically
pair<int, string> p4 = {3, "Priya"};                // brace initialization (C++11+)
auto p5 = make_pair(4, "Rahul");                       // auto + make_pair — very common combo

2. Accessing Members — .first and .second

pair<int, string> p = {1, "Vinit"};

cout << p.first << endl;    // 1
cout << p.second << endl;     // Vinit

p.first = 100;                    // members are directly mutable
p.second = "Changed";
cout << p.first << " " << p.second; // 100 Changed

3. Comparison Operators

Pairs support all relational operators, compared lexicographically: .first is compared first; if equal, .second is compared as a tiebreaker. 

pair<int, int> p1 = {1, 5};
pair<int, int> p2 = {1, 3};
pair<int, int> p3 = {2, 0};

cout << (p1 > p2);   // true — first elements equal (1==1), compare second: 5 > 3
cout << (p1 < p3);     // true — first elements differ: 1 < 2, second never even checked

This lexicographic comparison is exactly why pairs are commonly sorted directly — a vector<pair<int,int>> can be passed straight to sort() and it will order correctly by .first, then .second, with zero custom comparator code needed.

4. Common Use Cases

Sorting parallel data by one key

vector<pair<int, string>> students = {{85, "Vinit"}, {92, "Aman"}, {78, "Priya"}};

sort(students.begin(), students.end());   // sorts by .first (marks), ascending, automatically

for (auto &s : students) {
    cout << s.first << " " << s.second << endl;
}
// 78 Priya
// 85 Vinit
// 92 Aman

// To sort DESCENDING by marks, use a custom comparator:
sort(students.begin(), students.end(), greater<pair<int,string>>());

Returning two values from a function

pair<int, int> minMax(vector<int> &v) {
    int mn = v[0], mx = v[0];
    for (int x : v) {
        mn = min(mn, x);
        mx = max(mx, x);
    }
    return {mn, mx};   // returns a pair — cleaner than output parameters or a custom struct
}

int main() {
    vector<int> v = {5, 2, 9, 1, 7};
    pair<int, int> result = minMax(v);
    cout << "Min: " << result.first << ", Max: " << result.second;
    return 0;
}

Storing coordinates / graph edges (very common in DSA — Module 6.8)

pair<int, int> point = {3, 4};          // (x, y) coordinate
vector<pair<int, int>> edges;             // list of (u, v) graph edges
edges.push_back({0, 1});
edges.push_back({1, 2});

5. Nested Pairs

pair<int, pair<int, int>> nested = {1, {2, 3}};
cout << nested.first;             // 1
cout << nested.second.first;        // 2
cout << nested.second.second;         // 3

For three or more grouped values, std::tuple (Module 5.7) is generally cleaner than deeply nested pairs.

6. pair as a map Element (preview — full depth in Module 4.4)

map<string, int> ages = {{"Vinit", 22}, {"Aman", 20}};

for (pair<const string, int> &entry : ages) {   // each element IS a pair<const Key, Value>
    cout << entry.first << ": " << entry.second << endl;
}
// or, more idiomatically with auto:
for (auto &entry : ages) {
    cout << entry.first << ": " << entry.second << endl;
}

Practice Questions

Conceptual

  1. Explain how pair comparison operators work — what happens when the .first values are equal?
  2. Why is make_pair often used instead of directly specifying pair<T1, T2>?
  3. Why is a map's element type pair<const Key, Value> specifically — why is the key const?
  4. Give a scenario where returning a pair from a function is cleaner than using output/reference parameters.

Coding

  1. Write a function that takes a vector<int> and returns a pair<int, int> containing the two indices of the pair of elements that sum closest to a target value (brute-force is fine here).
  2. Write a program that stores a list of (name, score) pairs, sorts them by score descending, and prints the top 3.
  3. Write a program that reads a list of graph edges as pairs (u, v) and builds an adjacency list representation using vector<vector<int>>.
  4. Write a function pair<int,int> divmod(int a, int b) that returns both the quotient and remainder of integer division as a single pair.
