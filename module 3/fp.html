Module 3.4 — Function Pointers

Just as a pointer can store the address of a variable, a function pointer can store the address of a function — allowing functions to be passed as arguments, stored in variables, and called indirectly. This is foundational to the callback pattern used throughout C and lower-level C++ code (and conceptually connects directly to lambdas and std::function in Module 5).

1. Basic Syntax

int add(int a, int b) {
    return a + b;
}

int main() {
    int (*funcPtr)(int, int) = add;   // funcPtr stores the ADDRESS of the add function

    cout << funcPtr(3, 4);              // calls add(3, 4) indirectly through the pointer → 7
    cout << (*funcPtr)(3, 4);             // equivalent, more explicit dereference syntax → 7
    return 0;
}

Reading the declaration: int (*funcPtr)(int, int) — funcPtr is a pointer to a function that takes two ints and returns an int. The parentheses around *funcPtr are mandatory — without them, int *funcPtr(int, int) would instead declare a function that returns an int*, which is a completely different meaning.

2. Assigning Different Functions to the Same Pointer

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
int multiply(int a, int b) { return a * b; }

int main() {
    int (*operation)(int, int);

    operation = add;
    cout << operation(5, 3) << endl; // 8

    operation = subtract;
    cout << operation(5, 3) << endl;   // 2

    operation = multiply;
    cout << operation(5, 3) << endl;     // 15
    return 0;
}

This is the essence of function pointers' power: the same variable, and the same calling code, can dynamically invoke completely different logic depending on which function it currently points to.

3. Passing Functions as Arguments (Callbacks)

A common and powerful pattern: pass a function pointer as a parameter, so a general-purpose function can call back into custom, caller-supplied logic. 

int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }

// `operation` is a function pointer parameter — accepts ANY function matching int(int, int)
int compute(int x, int y, int (*operation)(int, int)) {
    return operation(x, y);
}

int main() {
    cout << compute(4, 5, add) << endl;         // 9 — add is passed AS a value (its address)
    cout << compute(4, 5, multiply) << endl;       // 20
    return 0;
}

A Practical Example — Custom Sort Comparator

#include <algorithm>
#include <vector>
using namespace std;

bool descending(int a, int b) {
    return a > b;   // returning true means "a should come before b"
}

int main() {
    vector<int> nums = {5, 2, 8, 1, 9};
    sort(nums.begin(), nums.end(), descending);  // passing a function pointer as the comparator

    for (int n : nums) cout << n << " ";  // 9 8 5 2 1
    return 0;
}

This exact pattern — passing a function (or, in modern code, a lambda) as a comparator — is used constantly throughout STL algorithms in Module 4.7.

4. Arrays of Function Pointers

Useful for building simple dispatch tables (e.g., menu-driven programs, simple calculators):

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
int multiply(int a, int b) { return a * b; }

int main() {
    int (*operations[3])(int, int) = {add, subtract, multiply};

    int choice = 1; // 0=add, 1=subtract, 2=multiply
    cout << operations[choice](10, 4); // 6 (subtract)
    return 0;
}

5. typedef / using for Readability

Function pointer syntax is notoriously hard to read — type aliases make it much cleaner:

typedef int (*Operation)(int, int);       // C-style alias
using OperationAlias = int(*)(int, int);   // modern C++11+ alias (preferred)

int add(int a, int b) { return a + b; }

int compute(int x, int y, Operation op) {   // MUCH more readable parameter type
    return op(x, y);
}

int main() {
    Operation op = add;
    cout << compute(3, 4, op); // 7
    return 0;
}

6. Function Pointers vs Modern Alternatives (preview)

Function pointers are the low-level foundation for callbacks, but modern C++ (Module 5.2, 5.7) offers more flexible alternatives: lambdas (anonymous inline functions, often capturing surrounding variables) and std::function (a general-purpose wrapper that can hold a function pointer, lambda, or any callable object). Raw function pointers cannot capture surrounding state the way lambdas can — this is their main limitation. 

// Preview — Module 5.2 covers this in full depth
#include <functional>
function<int(int,int)> op = [](int a, int b) { return a + b; }; // lambda stored in std::function
cout << op(3, 4); // 7
