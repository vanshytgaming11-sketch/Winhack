Module 7.1 — Mixed Practice Set

This module is structured differently from Modules 1–6: instead of teaching new concepts, it's a randomized, timed practice framework that forces you to first identify which pattern from Module 6 applies, before solving — this "pattern recognition under uncertainty" is the actual skill real interviews test, and it's not exercised by working through problems in topic order.

1. Why Mixed (Not Topic-Ordered) Practice Matters

When you solve 10 sliding window problems in a row (as in Module 6.2's practice questions), you already know it's a sliding window problem before reading it — the hard part is skipped. A real interview gives no such hint. This module's purpose is to remove that hint and rebuild the recognition step as a deliberate skill.

2. How to Structure a Practice Session

3. Problem Set Structure — Spanning All of Module 6

Each set below intentionally mixes topics — do not solve them in order without first identifying the pattern for each independently. Suggested pacing: one set per session, 45–60 minutes total.

Practice Set A

  1. Given an array of integers, find the length of the longest subarray with a sum equal to a given target (positive and negative numbers allowed).
  2. Given the root of a binary tree, return the sum of values of its deepest leaves.
  3. Given a list of flight tickets as (departure, arrival) pairs, reconstruct the itinerary assuming it starts from "JFK" (hint: this is a graph traversal in disguise).
  4. Given an array of coin denominations and a target amount, determine the FEWEST number of coins needed to make that amount (or -1 if impossible).
  5. Given a string, determine if it can be rearranged into a palindrome (no need to construct it — just determine feasibility).

Practice Set B

  1. Given a matrix of 0s and 1s, find the largest square containing only 1s (hint: this is 2D DP).
  2. Given a linked list, determine if it's a palindrome, using O(1) extra space.
  3. Given an array of intervals, merge all overlapping intervals.
  4. Given a set of courses with prerequisites, determine if it's possible to finish all courses (hint: this is cycle detection on a directed graph).
  5. Given an array, find the K closest values to a given target X, returned in sorted order.

Practice Set C

  1. Given a 2D grid representing a maze with obstacles, find the number of unique paths from top-left to bottom-right, moving only right or down.
  2. Given an array representing a histogram, and an amount of rainfall, compute the total water trapped.
  3. Given a string, generate all possible valid IP address combinations that can be formed from it.
  4. Implement an LRU (Least Recently Used) cache with O(1) get and put operations (hint: combine a hash map with a doubly linked list).
  5. Given a set of words, find if two words in the set are connected via a chain of single-letter transformations, each intermediate word also in the set (word ladder — BFS on an implicit graph).

4. Self-Diagnostic Questions After Each Problem

  • Did I correctly identify the pattern within the first 5 minutes, or did I need to try (and abandon) a wrong approach first?
  • Was my stated complexity target actually achieved by my final solution?
  • Did I handle the edge cases (empty input, single element, all-same values) without needing to patch my solution afterward?
  • Could I explain my approach out loud, clearly, in under 60 seconds?

Answering "no" to any of these is exactly the signal Module 7.3 (Weak-Area Review) is designed to act on.

Practice Questions

The three problem sets above ARE this sub-topic's practice questions — there are no additional questions beyond them. Complete one full set per session, following the six-step structure in section 2, before moving to Module 7.2.
