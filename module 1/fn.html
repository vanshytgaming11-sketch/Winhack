Module 1.3 — Functions

A function is a named, reusable block of code that performs a specific task. Functions let you break a program into smaller, manageable pieces, avoid code duplication, and make programs easier to test and maintain.

1. Function Declaration & Definition

A function has two parts: a declaration (also called a prototype — tells the compiler the function's name, return type, and parameters) and a definition (the actual body/implementation). 

// Declaration (prototype) — usually in a header or before main()
int add(int a, int b);

int main() {
    int result = add(3, 4); // Function CALL
    cout << result << endl; // 7
    return 0;
}

// Definition — the actual implementation
int add(int a, int b) {
    return a + b;
}

Why declare separately from defining? The compiler reads top to bottom. If main() calls add() before the compiler has seen add()'s definition, it needs the declaration first so it knows the function exists, what it returns, and what arguments it expects. Without a prior declaration or definition, you'd get a compile error: "'add' was not declared in this scope."

// Declaration + definition combined (most common when function is small
// or defined before it's used — no separate prototype needed)
int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(3, 4) << endl;
    return 0;
}

Anatomy of a Function

2. Parameters & Return Values

Functions with no parameters / no return value

void greet() {
    cout << "Hello!" << endl;
    // no return statement needed — void means "returns nothing"
}

int main() {
    greet(); // Called like this, no value to capture
    return 0;
}

Functions with parameters and a return value

int square(int n) {
    return n * n;
}

int main() {
    int result = square(5); // result = 25
    cout << square(5) + square(3) << endl; // 25 + 9 = 34
    return 0;
}

Multiple return points

A function can have multiple return statements, but execution stops at whichever one runs first.

string checkSign(int n) {
    if (n > 0) return "Positive";
    if (n < 0) return "Negative";
    return "Zero";
}

Local variables and scope inside functions

Variables declared inside a function are local to it — they're created when the function is called and destroyed when it returns. They are not accessible outside the function.

int add(int a, int b) {
    int sum = a + b; // local to add()
    return sum;
}

int main() {
    cout << sum; // COMPILE ERROR — sum is not visible here
    return 0;
}

3. Pass by Value vs Pass by Reference

This is one of the most frequently tested C++ concepts in interviews. It determines whether a function can modify the caller's original variable.

Pass by Value (default)

A copy of the argument is made and passed into the function. Changes inside the function do NOT affect the original variable.

void increment(int x) {
    x = x + 1; // modifies the COPY only
}

int main() {
    int a = 5;
    increment(a);
    cout << a; // Still 5 — original is unchanged
    return 0;
}

Pass by Reference (using &)

Instead of copying the value, the function receives an alias (direct reference) to the original variable. Changes inside the function DO affect the caller's original variable.

void increment(int &x) {
    x = x + 1; // modifies the ORIGINAL directly
}

int main() {
    int a = 5;
    increment(a);
    cout << a; // 6 — original IS changed
    return 0;
}

Pass by Pointer (alternative way to achieve reference-like behavior)

void increment(int *x) {
    *x = *x + 1; // dereference, then modify
}

int main() {
    int a = 5;
    increment(&a); // must pass the ADDRESS
    cout << a; // 6
    return 0;
}

Pass by Const Reference (efficiency + safety — very common in real code)

Passing large objects (like a std::string or a std::vector) by value copies the entire object every call — expensive. Passing by reference avoids the copy, but allows the function to modify the caller's data — often undesirable. const & gives you the best of both: no copy, and the compiler prevents modification. 

void printName(const string &name) {
    cout << name << endl;
    // name = "hacked"; // COMPILE ERROR — const prevents modification
}

4. Default Arguments

You can give parameters default values, used automatically when the caller omits that argument.

void greet(string name, string greeting = "Hello") {
    cout << greeting << ", " << name << "!" << endl;
}

int main() {
    greet("Vinit");                 // Hello, Vinit!  (uses default)
    greet("Vinit", "Good morning"); // Good morning, Vinit!  (overrides default)
    return 0;
}

Rule: Once a parameter has a default value, every parameter after it must also have one (defaults must be trailing/rightmost).

void f(int a, int b = 5, int c);       // COMPILE ERROR — c has no default after b does
void f(int a, int b = 5, int c = 10);  // VALID

Default arguments are specified in the declaration, not repeated in the definition if they're separate:

void greet(string name, string greeting = "Hello"); // declaration — default here

void greet(string name, string greeting) { // definition — NO default repeated here
    cout << greeting << ", " << name << "!" << endl;
}

5. Function Overloading

C++ allows multiple functions with the same name as long as their parameter lists differ (in number of parameters, or parameter types). The compiler picks the correct one at compile time based on the arguments used in the call — this is a form of compile-time (static) polymorphism. 

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    cout << add(2, 3) << endl;         // calls int version → 5
    cout << add(2.5, 3.5) << endl;       // calls double version → 6.0
    cout << add(1, 2, 3) << endl;          // calls 3-param version → 6
    return 0;
}

What makes overloads valid:

  • Different number of parameters, OR
  • Different parameter types (return type ALONE is not enough to distinguish overloads)
int f(int x);
double f(int x); // COMPILE ERROR — differs only by return type, not allowed

Ambiguous Overload Calls (common interview trap)

void f(int x)    { cout << "int version"; }
void f(double x) { cout << "double version"; }

int main() {
    f(5);     // calls int version — exact match
    f(5.0);   // calls double version — exact match
    f('a');    // calls int version — char promotes to int
    f(5L);      // AMBIGUOUS in some cases — long could convert to either int or double
    return 0;
}

6. Recursion

A recursive function is one that calls itself, directly or indirectly, to solve a smaller instance of the same problem. Every recursive function needs two essential parts:

  • Base case — the condition where the function stops calling itself and returns directly (prevents infinite recursion).
  • Recursive case — where the function calls itself with a smaller/simpler input, moving toward the base case.

Example: Factorial

int factorial(int n) {
    if (n == 0 || n == 1) return 1;  // BASE CASE
    return n * factorial(n - 1);      // RECURSIVE CASE
}

int main() {
    cout << factorial(5); // 120
    return 0;
}

Tracing the Call Stack

factorial(5)
= 5 * factorial(4)
    = 5 * (4 * factorial(3))
        = 5 * (4 * (3 * factorial(2)))
            = 5 * (4 * (3 * (2 * factorial(1))))
                = 5 * (4 * (3 * (2 * 1)))     ← base case hit, starts unwinding
            = 5 * (4 * (3 * 2))
        = 5 * (4 * 6)
    = 5 * 24
= 120

Each recursive call adds a new stack frame to the call stack (storing that call's local variables and return address). This is why deep/unbounded recursion causes a stack overflow — every call consumes stack memory, and there's no free lunch: recursion trades code elegance for stack space.

Example: Fibonacci (illustrates recursive inefficiency)

int fib(int n) {
    if (n <= 1) return n; // base case
    return fib(n - 1) + fib(n - 2); // two recursive calls
}

This has exponential time complexity O(2ⁿ) because it recomputes the same subproblems repeatedly (e.g., fib(3) is computed multiple times while computing fib(5)). This exact inefficiency motivates memoization/dynamic programming, covered in depth in Module 6.10.

Example: Sum of digits (a common interview warm-up)

int sumOfDigits(int n) {
    if (n == 0) return 0;               // base case
    return (n % 10) + sumOfDigits(n / 10); // recursive case
}
// sumOfDigits(1234) → 4 + sumOfDigits(123)
//                   → 4 + 3 + sumOfDigits(12)
//                   → 4 + 3 + 2 + sumOfDigits(1)
//                   → 4 + 3 + 2 + 1 + sumOfDigits(0)
//                   → 4 + 3 + 2 + 1 + 0 = 10

Every loop can be rewritten as recursion, and vice versa

// Iterative
int factorialIter(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) result *= i;
    return result;
}

// Recursive (equivalent)
int factorialRec(int n) {
    if (n <= 1) return 1;
    return n * factorialRec(n - 1);
}

Conceptual

  2. Why can't two functions be overloaded if they differ only in return type?
  3. What is the rule regarding default arguments and parameter order? Why does this rule exist?
  4. Explain what happens on the call stack when a recursive function executes, and why unbounded recursion causes a stack overflow.
  5. Why is passing a large std::string by const & generally better than passing it by value?

Coding

  1. Write a function bool isPrime(int n) and use it in main() to print all prime numbers between 1 and 50.
  2. Write a function void swap(int &a, int &b) that swaps two integers using pass-by-reference (no third variable, no return value).
  3. Write an overloaded function area() — one version takes a single double (circle, radius), one takes two doubles (rectangle, length & width), and one takes three doubles (triangle, using Heron's formula with three sides).
  4. Write a recursive function int power(int base, int exp) that computes base^exp without using pow(). Then write an iterative version and compare.
  5. Write a recursive function to reverse a string in place (no built-in reverse functions allowed).
  6. Write a recursive function int gcd(int a, int b) implementing Euclid's algorithm, and trace its call stack for gcd(48, 18) in a comment above the function.
