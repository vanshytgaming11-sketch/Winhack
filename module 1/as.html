Module 1.4 — Arrays & Strings

1. Arrays — Introduction

An array is a fixed-size, contiguous block of memory that stores multiple elements of the same data type, accessed using an index. Because elements sit next to each other in memory, array access is O(1) — the address of any element can be computed directly from the base address and the index.

Declaration & Initialization

int arr[5];                       // Declaration only — elements contain garbage values
int arr[5] = {1, 2, 3, 4, 5};      // Declaration + full initialization
int arr[5] = {1, 2};               // Partial init — remaining elements auto-initialized to 0
int arr[] = {1, 2, 3, 4, 5};       // Size inferred from initializer list → size 5
int arr[5] = {0};                  // All elements initialized to 0
int arr[5] = {};                   // Also all elements initialized to 0 (C++11+)

Accessing Elements

int arr[5] = {10, 20, 30, 40, 50};

cout << arr[0]; // 10 — first element (indexing starts at 0)
cout << arr[4]; // 50 — last element (index = size - 1)

arr[2] = 99;      // modifies the element at index 2
cout << arr[2];    // 99

Critical interview point — no bounds checking:

int arr[5] = {1, 2, 3, 4, 5};
cout << arr[10]; // COMPILES, but is UNDEFINED BEHAVIOR
                  // C++ does NOT check array bounds at compile or run time.
                  // This reads garbage memory (or crashes) — a classic source of bugs
                  // and a very common interview "what's wrong with this code" question.

Traversing an Array

int arr[5] = {10, 20, 30, 40, 50};

// Classic indexed loop
for (int i = 0; i < 5; i++) {
    cout << arr[i] << " ";
}

// Range-based for loop (C++11+) — cleaner, no index management
for (int val : arr) {
    cout << val << " ";
}

// Using sizeof to compute length generically (only works while arr is a real array, NOT a decayed pointer)
int size = sizeof(arr) / sizeof(arr[0]); // 20 / 4 = 5
for (int i = 0; i < size; i++) {
    cout << arr[i] << " ";
}

2. 2D Arrays

A 2D array is essentially an "array of arrays" — commonly used to represent matrices, grids, or tables.

int matrix[3][4]; // 3 rows, 4 columns

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// Accessing an element
cout << matrix[1][2]; // Row 1, Column 2 → 6

// Traversing a 2D array
for (int i = 0; i < 2; i++) {         // rows
    for (int j = 0; j < 3; j++) {      // columns
        cout << matrix[i][j] << " ";
    }
    cout << endl;
}
// Output:
// 1 2 3
// 4 5 6

Memory layout — row-major order: C++ stores 2D arrays row by row in contiguous memory. This matters for cache performance — iterating row-by-row (outer loop = row, inner loop = column) is much faster than column-by-column, because it accesses memory sequentially.

// FAST — sequential memory access (row-major traversal)
for (int i = 0; i < rows; i++)
    for (int j = 0; j < cols; j++)
        sum += matrix[i][j];

// SLOWER — jumps around in memory (column-major traversal on a row-major array)
for (int j = 0; j < cols; j++)
    for (int i = 0; i < rows; i++)
        sum += matrix[i][j];

3. Arrays and Pointers (preview)

An array name, when used in most expressions, "decays" into a pointer to its first element. This is a foundational concept fully explored in Module 1.5, but it's worth previewing here: 

int arr[5] = {10, 20, 30, 40, 50};
cout << arr;      // prints an ADDRESS (arr decays to a pointer to arr[0])
cout << *arr;      // 10 — dereferencing gives the first element
cout << *(arr + 2); // 30 — pointer arithmetic == arr[2]

4. C-Style Strings

Before std::string, C++ (inheriting from C) represented text as a character array terminated by a null character '\0'. Understanding these is important because they still appear in legacy code, low-level APIs, and are a common interview topic. 

char str1[6] = {'H', 'e', 'l', 'l', 'o', '\0'}; // manual, must include null terminator
char str2[] = "Hello";                            // compiler auto-adds '\0' — size becomes 6
char str3[20] = "Hello";                           // extra space reserved beyond the string content

cout << str2; // Hello  — cout stops printing at '\0'

Why the null terminator matters: C-style strings have no stored length — functions that operate on them (like strlen, or cout <<) scan forward byte by byte until they hit '\0'. If the terminator is missing or overwritten, these functions read into adjacent memory — undefined behavior, and a classic source of buffer overflow bugs.

Common <cstring> Functions

FunctionPurposeExample
strlen(s)Returns length (excluding '\0')strlen("Hello") → 5
strcpy(dest, src)Copies src into deststrcpy(a, "Hi")
strcat(dest, src)Appends src to end of deststrcat(a, b)
strcmp(s1, s2)Lexicographic compare; returns 0 if equal, <0 or >0 otherwisestrcmp("abc","abd") → negative
 
#include <cstring>
using namespace std;

int main() {
    char a[20] = "Hello";
    char b[] = " World";

    cout << strlen(a) << endl;   // 5

    strcat(a, b);                  // a becomes "Hello World"
    cout << a << endl;

    char c[20];
    strcpy(c, "Copied!");
    cout << c << endl;             // Copied!

    cout << strcmp("apple", "banana") << endl; // negative — 'a' < 'b'
    cout << strcmp("apple", "apple") << endl;  // 0 — equal
    return 0;
}

Danger with strcpy/strcat: They don't check destination buffer size — if src is longer than dest's allocated space, this silently overflows into adjacent memory. This is precisely why std::string is strongly preferred in modern C++.

5. std::string

std::string (from <string>) is C++'s dynamically-sized, memory-safe string class. It manages its own memory automatically (grows/shrinks as needed), tracks its own length, and provides rich member functions — eliminating most of the pitfalls of C-style strings. 

#include <string>
using namespace std;

string s1 = "Hello";
string s2("World");
string s3 = s1 + " " + s2;   // Concatenation with + — "Hello World"
string s4(5, 'x');            // "xxxxx" — 5 copies of 'x'

Common Operations

string s = "Hello, World!";

cout << s.length() << endl;   // 13  (also: s.size() — identical, both O(1))
cout << s[0] << endl;          // H  — indexed access, like an array
cout << s.at(0) << endl;        // H  — like [], but throws std::out_of_range if index is invalid

s[0] = 'J';                       // Modifies in place — s becomes "Jello, World!"

cout << s.substr(0, 5) << endl;   // "Jello" — substring starting at index 0, length 5
cout << s.substr(7) << endl;        // "World!" — from index 7 to the end

cout << s.find("World") << endl;     // 7 — index where "World" starts (string::npos if not found)
if (s.find("xyz") == string::npos) {
    cout << "Not found" << endl;
}

s.append("!!!");                       // Adds to the end — s becomes "Jello, World!!!!"
s.push_back('?');                       // Adds a single character to the end
s.pop_back();                            // Removes the last character

s.insert(5, " there");                     // Inserts a string at index 5
s.erase(5, 6);                              // Removes 6 characters starting at index 5

cout << s.empty() << endl;                    // false (0) — checks if string is empty

reverse(s.begin(), s.end());                   // Requires <algorithm> — reverses the string in place
sort(s.begin(), s.end());                       // Requires <algorithm> — sorts characters in place

String Comparison

string a = "apple", b = "banana";
cout << (a == b);   // false
cout << (a < b);     // true — lexicographic comparison, 'a' < 'b'

String Concatenation Gotcha

string s = "Value: " + 5;         // COMPILE ERROR — can't add int directly to a C-string literal like this
string s = "Value: " + to_string(5); // CORRECT — to_string() converts int → string first
cout << s;                             // "Value: 5"

Iterating a std::string

string s = "Hello";

for (int i = 0; i < s.length(); i++) {
    cout << s[i] << " ";
}

for (char c : s) {          // range-based — cleaner
    cout << c << " ";
}

for (char &c : s) {          // reference — can modify characters in place
    c = toupper(c);           // requires <cctype>
}
cout << s;                     // HELLO

6. Common Array/String Interview Patterns (preview)

These specific techniques get their own deep dive in Module 6.2, but a first exposure here helps connect fundamentals to problem-solving:

  • Two-pointer technique — using two indices moving toward/away from each other (e.g., checking if a string is a palindrome).
  • Frequency counting — using an array or map indexed by character/value to count occurrences (e.g., checking anagrams).
  • Sliding window — maintaining a moving subrange of an array/string to solve subarray/substring problems efficiently.
// Quick example: check if a string is a palindrome using two pointers
bool isPalindrome(string s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++;
        right--;
    }
    return true;
}

Practice Questions

Conceptual

  1. Why does accessing arr[10] on a 5-element array compile successfully but produce undefined behavior at runtime?
  2. Explain why row-major traversal of a 2D array is generally faster than column-major traversal.
  3. What is the null terminator, and why is it essential for C-style strings? What happens if it's missing or overwritten?
  4. Compare s[i] and s.at(i) for a std::string — when would you prefer one over the other?
  5. Why does string s = "Value: " + 5; fail to compile, and how do you fix it?

Coding

  1. Write a program that finds the largest and smallest elements in an array in a single pass (one loop, tracking both simultaneously).
  2. Write a program that reverses an array in place, without using any extra array (swap elements from both ends toward the middle).
  3. Write a program that checks whether two strings are anagrams of each other, using a frequency-count array of size 26 (assume lowercase letters only).
  4. Write a program that takes a sentence and counts the number of vowels, consonants, digits, and spaces in it.
  5. Write a program using a 2D array to store and print a 3x3 matrix, then compute and print the transpose of that matrix.
  6. Write a program that removes all duplicate characters from a string, preserving the order of first occurrence (e.g., "programming" → "progamin").
