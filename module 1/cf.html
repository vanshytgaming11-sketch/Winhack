Module 1.2 — Control Flow

Control flow statements determine the order in which instructions execute. By default, C++ executes statements sequentially, top to bottom — control flow constructs let you branch, repeat, or skip execution based on conditions.

1. The if / else if / else Statement

Basic if

int age = 20;
if (age >= 18) {
    cout << "Adult" << endl;
}

The block {} executes only if the condition inside () evaluates to true (non-zero). If the block has a single statement, {} is technically optional — but omitting it is a common source of bugs (see below), so always use braces.

if / else

int age = 15;
if (age >= 18) {
    cout << "Adult" << endl;
} else {
    cout << "Minor" << endl;
}

if / else if / else chain

int marks = 72;

if (marks >= 90) {
    cout << "Grade A" << endl;
} else if (marks >= 75) {
    cout << "Grade B" << endl;
} else if (marks >= 60) {
    cout << "Grade C" << endl;
} else {
    cout << "Grade F" << endl;
}
// Output: Grade C

Only one branch executes — the first condition that evaluates to true. Order matters: conditions are checked top-to-bottom, and evaluation stops at the first match.

The Dangling else Problem (classic interview trap)

if (a > 0)
    if (b > 0)
        cout << "Both positive";
else
    cout << "a is not positive";  // WRONG ASSUMPTION!

The else always binds to the nearest unmatched if — so this else actually pairs with if (b > 0), NOT if (a > 0), even though the indentation misleadingly suggests otherwise. This prints nothing if a <= 0, which is likely not the intended behavior.

Fix — always use braces:

if (a > 0) {
    if (b > 0) {
        cout << "Both positive";
    }
} else {
    cout << "a is not positive";
}

Nested Conditions

int a = 15, b = 20, c = 10;

if (a > b) {
    if (a > c) {
        cout << "a is largest" << endl;
    } else {
        cout << "c is largest" << endl;
    }
} else {
    if (b > c) {
        cout << "b is largest" << endl;
    } else {
        cout << "c is largest" << endl;
    }
}

Deep nesting hurts readability. In interviews, prefer combining conditions or using early returns where possible:

// Cleaner alternative using logical operators
if (a >= b && a >= c) cout << "a is largest";
else if (b >= a && b >= c) cout << "b is largest";
else cout << "c is largest";

2. The switch Statement

switch is used when comparing a single variable against multiple constant values — a cleaner alternative to long if-else if chains in that specific case.

int day = 3;

switch (day) {
    case 1:
        cout << "Monday";
        break;
    case 2:
        cout << "Tuesday";
        break;
    case 3:
        cout << "Wednesday";
        break;
    case 4:
        cout << "Thursday";
        break;
    default:
        cout << "Invalid day";
}
// Output: Wednesday

Rules & Constraints

  • The switch expression must evaluate to an integral or enum type (int, char, enum — NOT float, double, or string in standard C++).
  • case labels must be compile-time constants (no variables, no ranges like case 1-5:).
  • default is optional but strongly recommended — catches unhandled cases.
  • break exits the switch. Without break, execution "falls through" to the next case.

Fall-Through Behavior (heavily tested in interviews)

int x = 2;

switch (x) {
    case 1:
        cout << "One ";
    case 2:
        cout << "Two ";
    case 3:
        cout << "Three ";
        break;
    case 4:
        cout << "Four ";
}
// Output: Two Three
// Execution starts at case 2 and "falls through" into case 3
// because there's no break after case 2, then stops at the break in case 3.

Fall-through can be intentional — used to group multiple cases with shared logic:

char grade = 'B';

switch (grade) {
    case 'A':
    case 'B':
    case 'C':
        cout << "Pass";
        break;
    case 'F':
        cout << "Fail";
        break;
    default:
        cout << "Invalid grade";
}
// Output: Pass
// case 'A', 'B', 'C' share the same code block since they have no break between them

switch vs if-else — When to use which

Use switch whenUse if-else when
Comparing one variable against several constantsComparing ranges (x > 10 && x < 20)
Values are integral/enum/charComparing multiple different variables
You want potentially faster jump-table dispatchConditions involve complex boolean logic

3. Loops

Loops repeat a block of code while a condition holds true.

for Loop

Best when the number of iterations is known/countable in advance.

for (int i = 0; i < 5; i++) {
    cout << i << " ";
}
// Output: 0 1 2 3 4

Anatomy of a for loop:

for (initialization; condition; update) {
    // body
}
  1. Initialization — runs once, before the loop starts (int i = 0).
  2. Condition — checked before every iteration; loop continues while true.
  3. Update — runs after each iteration's body (i++).
// Multiple variables in a for loop
for (int i = 0, j = 10; i < j; i++, j--) {
    cout << i << "-" << j << " ";
}
// Output: 0-10 1-9 2-8 3-7 4-6

// Infinite loop (deliberate, common in competitive programming with internal break)
for (;;) {
    cout << "runs forever unless broken" << endl;
    break; // needed to actually stop
}

// Reverse iteration
for (int i = 9; i >= 0; i--) {
    cout << i << " ";
}
// Output: 9 8 7 6 5 4 3 2 1 0

Range-based for loop (C++11+) — iterates directly over containers/arrays:

vector<int> nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    cout << n << " ";
}
// Output: 1 2 3 4 5

// Using reference to modify elements in place
for (int &n : nums) {
    n *= 2;
}
// nums is now {2, 4, 6, 8, 10}

// Using auto (type deduction, covered fully in Module 5.1)
for (auto &n : nums) {
    cout << n << " ";
}

while Loop

Best when the number of iterations is not known in advance — condition-driven repetition.

int i = 0;
while (i < 5) {
    cout << i << " ";
    i++;
}
// Output: 0 1 2 3 4

The condition is checked before each iteration — if false initially, the loop body never executes even once.

int i = 10;
while (i < 5) {
    cout << "never runs";
}
// No output

Common use case — reading input until a sentinel value:

int n;
cin >> n;
while (n != -1) {
    cout << "You entered: " << n << endl;
    cin >> n;
}

do-while Loop

Like while, but the condition is checked after the body executes — guarantees the body runs at least once.

int i = 10;
do {
    cout << i << " ";
    i++;
} while (i < 5);
// Output: 10  (runs once, even though condition is false from the start)

Classic use case — menu-driven programs where you want to show the menu at least once:

int choice;
do {
    cout << "1. Add\n2. Delete\n3. Exit\nEnter choice: ";
    cin >> choice;
    // process choice
} while (choice != 3);

for vs while vs do-while — Summary

LoopCondition checkedGuaranteed executionBest for
forBefore each iterationNo (0 or more times)Known iteration count
whileBefore each iterationNo (0 or more times)Unknown iteration count, condition-driven
do-whileAfter each iterationYes (at least once)Menu loops, "run first, check later"

4. break and continue

break

Immediately exits the innermost enclosing loop or switch statement.

for (int i = 0; i < 10; i++) {
    if (i == 5) break;
    cout << i << " ";
}
// Output: 0 1 2 3 4  (stops before printing 5)

break only exits ONE level of nesting:

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break; // only breaks the INNER loop
        cout << i << "," << j << " ";
    }
}
// Output: 0,0  1,0  2,0
// The outer loop continues normally; only the inner loop stops early each time

To break out of nested loops entirely, common approaches:

// Using a flag
bool stop = false;
for (int i = 0; i < 3 && !stop; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) { stop = true; break; }
        cout << i << "," << j << " ";
    }
}

// Using goto (rare, but valid — sometimes cleanest for deeply nested breaks)
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) goto done;
        cout << i << "," << j << " ";
    }
}
done:
cout << "Done";

continue

Skips the rest of the current iteration and jumps to the next one (re-evaluates the condition, or runs the update step in a for loop).

for (int i = 0; i < 5; i++) {
    if (i == 2) continue;
    cout << i << " ";
}
// Output: 0 1 3 4  (2 is skipped, loop continues)

Gotcha with while + continue — make sure the update happens before continue, or you'll get an infinite loop:

int i = 0;
while (i < 5) {
    if (i == 2) {
        i++;      // MUST update before continue, or infinite loop!
        continue;
    }
    cout << i << " ";
    i++;
}
// Output: 0 1 3 4

break vs continue — Summary

StatementEffect
breakExits the loop/switch entirely
continueSkips to the next iteration, loop keeps running

  2. Write a program that prints all prime numbers between 1 and 100 using nested loops and continue to skip non-prime checks efficiently.
